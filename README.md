## Sobre este portfólio

Este repositório reúne projetos e laboratórios **hands-on em AWS, Cloud Computing, Linux e automação de infraestrutura**.

O objetivo é demonstrar, por meio de projetos práticos e documentação técnica, minha capacidade de **provisionar recursos, configurar ambientes, automatizar tarefas e compreender arquiteturas de nuvem**.

Os conteúdos começaram como parte da minha formação em AWS e continuam evoluindo com projetos próprios e novos estudos.

## ⭐ Projetos em destaque

### Projeto 01 — VPC + Application Load Balancer

Arquitetura de alta disponibilidade utilizando componentes de rede e balanceamento da AWS.

**Principais conceitos:** VPC, subnets, route tables, security groups, EC2 e Application Load Balancer.

➡️ [`Projeto-01-VPC-ALB`](./Projeto-01-VPC-ALB)

### AWS CLI — ELB + Auto Scaling

Laboratório focado na criação e gerenciamento de recursos AWS utilizando a linha de comando.

**Principais conceitos:** AWS CLI, ELB, Auto Scaling e EC2.

➡️ [`aws-cli-elb-autoscaling`](./aws-cli-elb-autoscaling)

### AWS Serverless Inventory

Projeto utilizando serviços gerenciados e arquitetura serverless para trabalhar com dados de inventário.

**Principais conceitos:** Lambda, DynamoDB e S3.

➡️ [`aws-project-serverless-inventory`](./aws-project-serverless-inventory)
